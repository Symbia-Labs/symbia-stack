## Order of work

### 1. Catalog bootstrap — first, because it makes everything else real

`Failed to run bootstrap: duplicate key value violates unique constraint
"resources_pkey"`. It aborts on the first duplicate, so every bootstrap file
after the failure point is silently never applied. The running assistants are
pre-fix definitions.

**Do:** make bootstrap idempotent — upsert rather than insert, and do not let
one file's failure abort the rest. A file that fails should be reported as
failed, loudly, and the run should continue.

**Verified by:** restart the stack, ask chat `2+2`, and see the reply arrive
*without* `_computed by math.evaluate — no model call_`. That suffix is the
canary: it is a fix from 10 Aug that has never taken effect.

**Prediction to register before starting:** the abort is in the catalog
bootstrap loader's error handling, not in the data. If the data turns out to be
genuinely duplicated in a way upsert cannot resolve, that is a different and
more interesting problem.

### 2. Calc accepts natural language

`what is 2+2?` → `Invalid character: ?`. `2+2` → `4`. Raw message text reaches
the evaluator.

**Do:** extract the expression before evaluating. The guard on
`symbia.compute.arithmetic` already says only digits, whitespace and `+ - * / ( )`
survive — the assistant path needs the same discipline at the boundary.

**Verified by:** three phrasings in the browser — `what is 48271 * 1039?`,
`48271 * 1039`, and something with an `@` in it — all returning `Computed`.

### 3. Spyglass gesture interference

During the 5s countdown the overlay accepts nothing but cancellation, so
gestures performed in sequence eat each other.

**Do:** let a hold during a countdown cancel *and* start recording, rather than
only cancelling.

**Verified by:** operator runs all four gestures back to back and four artifacts
appear — a still, a video, a video+audio, an audio-only. Today that produced
one.

## What not to do

Written down because today's failure mode was volume, and it will recur unless
it is named.

- **No new proposals.** `docs/proposals/` gets nothing tomorrow. Five is
  already more argued-about-than-built than this project can carry.
- **No new library without a caller in the same session.** `@symbia/lineage`
  exists because that rule did not.
- **One document at the end**, updating STATUS and the walk results. Not seven.
- **Predictions must name a disconfirming observation.** "Something in the
  assistant path fails" is weather. "The suffix disappears from a live reply" is
  a prediction.
- **When a check passes, ask whether it could have failed.** Four separate
  instruments today agreed with their own assumptions — a tamper probe assuming
  four segments, a reformatting test that truncated its input, a `restart` test
  where `recreate` was the real case, and an entire suite that grepped for a
  February architecture.
